# TypeScript behavior parity

Reference: `main` at `4193cbb798f66371312aed979c17ab37fa69de3e` (v0.15.1).
Rust implementation: v0.16.1.

The expected results below were generated by running the original TypeScript
functions and OpenTUI test renderer with Bun in a temporary checkout. Normal
Cargo tests consume the JSON fixtures; they do not need Bun or the old sources.

## Exact comparisons

- Search: ordered IDs and sections, activity/history/visit ordering, current
  workspace demotion, query prefixes, aliases, paths, semantic titles, score
  ties, excluded metadata, and Unicode scores/highlights. Includes 42 targeted
  cases and 240 seeded mixed cases, alongside the original scorer fixture.
- Grouping: All category order versus query relevance, five-item previews,
  navigation rows, and 336 group-aware viewport cases.
- Session items: complete saved-item and merge JSON, phrase normalization,
  excerpts, and UTF-16 boundaries in long CJK/emoji conversations.
- Preview text: wrapping, literal highlighting, control characters, graphemes,
  terminal-cell clipping, bottom following, and scroll offsets.
- Resource overview text: workspace paths/tabs/panes and unopened worktrees.
- Screen characters: 34 frames generated by the original OpenTUI test renderer.
  Twelve cover browsing/search/prefix/empty results at 80/120/150 columns;
  twelve cover workspace/tab previews, narrow/wide layout, and expansion;
  ten cover prompts, update/retry/completion, and destination selection.
  Frames render the reference version (v0.15.1), independently of the current
  release version. Assertions ignore only trailing whitespace on each row.

Transcript search also retains the original two-stage `rg` coarse filter for
Codex and Claude, including escaped queries, conversation record probes, and
full-scan fallback on unknown layouts or failures. OpenCode exports use four
workers while publishing hits in input order. Real-`rg` tests cover the helper's
exit codes and candidate selection; CI installs ripgrep for these checks.

## Interaction coverage

Tests exercise metadata versus transcript-hit deduplication/counts, dynamic
category tabs, tab switching without restarting scans, identity-preserving
selection, pane selection, preview cancellation and caching, input cursor
placement, update notice clicks, and destination selection before confirmation.

These are deterministic comparisons of the tested states, not a claim that all
possible terminal/provider combinations are identical. Font rendering and color
appearance still depend on the terminal. Real provider accounts and mutating
Herdr operations are not used by these tests.

## Run

```sh
cargo test --locked --all-targets
cargo clippy --locked --all-targets -- -D warnings
cargo fmt --check
cargo build --release --locked --bin herdr-omni
```

Fixture sources are named by responsibility under `tests/fixtures`. To refresh
an oracle, restore the reference commit into a temporary directory, install its
locked Bun dependencies, run the corresponding TS export on the fixture's input,
and compare before replacing expected output. Do not generate expected values
from the Rust implementation being tested.

## Final local verification

117 tests passed, including the fixture matrices described above. Formatting,
Clippy with warnings denied, and the optimized release build passed on macOS.
A release-binary PTY test exercised Chinese transcript search, preview expansion,
Escape navigation, tiny-terminal resize recovery, and terminal restoration. A stalled-helper shutdown test
exited in 0.05 seconds and confirmed that eight helper processes/descendants exited.
The same tests and Clippy checks also passed in an isolated Linux container.
Hosted platform build results are recorded in the release workflow.

additional failure-path findings and regression coverage.
